# Toyota C-HR NGX10 / двигатель 8NR-FTS — паспорт и спецификации

Автомобиль: **Toyota C-HR, кузов 3BA-/DBA-NGX10 (2WD), 2020, правый руль, JDM**
Двигатель: **8NR-FTS** (1.2 turbo, серия NR)

## Спецификация 8NR-FTS

| Параметр | Значение |
|---|---|
| Объём | 1197 см³ (рядный 4-цил., DOHC 16V) |
| Диаметр × ход | 71,5 × 74,5 мм |
| Степень сжатия | 10,0:1 (цикл Аткинсона/Миллера на частичных нагрузках) |
| Мощность | 85 кВт (116 л.с. / PS) @ 5200–5600 rpm |
| Момент | 185 Н·м (18,9 кгс·м) @ 1500–4000 rpm |
| Впрыск | D-4T — прямой (форкамерный рейлинг forged, давление **2,4–20 МПа** в зависимости от режима) |
| Наддув | single-scroll turbo, водяное охлаждение, vacuum wastegate (WGT открыт при пуске → газы сразу в катализатор, ускоренный прогрев); жидкостно-воздушный интеркулер с отдельным контуром (свой радиатор + электропомпа, управляется ECM) |
| ГРМ | цепь 8 мм; VVT-i (выпуск) + VVT-iW (впуск, широкий диапазон) |
| Выпускной коллектор | интегрирован в ГБЦ, водяное охлаждение |
| Свечи | NGK DILKAR8J9G, зазор 0,8–0,9 мм |
| Масло | 0W-20; смена с фильтром **4,0 л** (JDM мануал C-HR, toyota-club.net) |
| ОЖ | **6,6 л двигатель + 1,9 л контур интеркулера** (2 отдельных бачка!) |
| Топливо | JDM — регулярный бензин RON 91 (無鉛レギュラー), бак 50 л |

## Особенности, важные для холодного пуска

- **Два термостата**: основной (узел `16031`, открытие 80–84 °C, закрыт ниже 77 °C) и термостат блока (`16331A`, ~76–80 °C) — перекрывает циркуляцию в блоке для быстрого прогрева.
- **Клапан воды (`Water Valve`, 16671)** на байпасе — управляет распределением потоков ОЖ.
- **Отдельный контур турбины/интеркулера**: свой бачок, радиатор, электропомпа — тепло туда идёт мимо печки.
- **Нет электрического PTC-догревателя** на бензиновых JDM NGX10 (только на гибридах в 寒冷地仕様) — салон греется только от антифриза.
- Малый объём + высокий КПД = мало «лишнего» тепла на холостом ходу; прогрев в движении значительно быстрее.

## Комплектации NGX10 (JDM)

- Тип кузова: 5-дверный SUV; габариты ~4360×1795×1565, база 2640 мм (до рестайла), масса ~1440–1470 кг.
- Трансмиссии: Super CVT-i (K114) либо 6МКПП; привод 2WD (NGX10) / 4WD (NGX50).
- Рестайлинг с октября 2019: 3BA-NGX10 (индексы типа AHXEX/AHFNX в каталогах).
