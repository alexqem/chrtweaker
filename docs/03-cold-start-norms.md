# Нормы холодного запуска и прогрева 8NR-FTS (NGX10)

Сводка допусков для сверки с логами (`logs/*.csv`). Проверять показатели **в контексте режима** (см. docs/05): одна цифра вне условий — не диагноз.

## Прогрев ОЖ

| Условие | Норма | Источник |
|---|---|---|
| После ночной стоянки | ECT ≈ IAT ≈ уличная температура (±2–3 °C) | Toyota SSM (диагностический критерий достоверности датчика) |
| Прогретый двигатель, рабочее окно | **75–100 °C** (Stop&Start data list на ХХ: 75–95 °C) | Toyota SSM |
| Основной термостат `16031` | открытие **80–84 °C**, закрыт **ниже 77 °C**, ход ≥8,0 мм @ 95 °C | Toyota RM / toyota-club.net |
| Термостат блока `16331A` | открытие **76–80 °C** | toyota-club.net «Двигатели серии NR» |
| Рост ECT на ХХ при 0 °C | шт. регламент времени прогрева НЕ нормируется — оценивать по динамике (см. docs/05) | — |
| Признак приоткрытого термостата | ECT не достигает 75 °C или падает в движении; патрубки радиатора теплеют до 70 °C | Toyota SSM (критерий P0116) |

## Обороты холостого хода

| Условие | Норма |
|---|---|
| Прогревочные (первые минуты) | повышенные, ~1100–1250 rpm (практика владельцев; заводской норматив в открытых документах отсутствует) |
| Прогретый ХХ, P/N, A/C off, **CVT** | **680–780 rpm** |
| Прогретый ХХ, P/N, A/C off, **6МКПП** | **600–700 rpm** |
| Падение к 0 / грубые скачки | признак проблемы ДПКВ/зажигания (P0335, P0300) |

## Топливные коррекции (Mode 01 PID 0x06/0x07)

| Условие | Норма |
|---|---|
| Здоровый двигатель, суммарный трим | примерно **±10 %** (практика/литература: Ross-Tech, rise-factory.jp — «total trim within ±10% is normal range») |
| Мониторинг Toyota активен при | Closed Loop, бортсеть ≥11 В, rpm <1100 или нагрузка ≥10 % |
| Порог DTC P017100 (бедная) | обученная коррекция **≥ +48 %** |
| Порог DTC P017200 (богатая) | **≤ −35 %** |
| Открытая петля на холодную | STFT/LTFT вне контроля замкнутой петли — не считать отклонением |

## Нагрузка и воздух (MAF / MAP / boost)

| Условие | Норма |
|---|---|
| MAF @ 3000 rpm (ECT ≥75 °C, P/N, A/C off) | **4,0–14,0 г/с** (Toyota SSM) |
| MAF на ХХ | заводская норма в открытых документах **отсутствует**; ориентир здорового 1.2T на ХХ ~1,5–3 г/с — сверять только по динамике между сессиями |
| MAP на прогретом ХХ | ~30–35 kPa (вакуум); boost = MAP − барометр ≈ −65…−70 kPa |
| Boost под нагрузкой | положительный; величина зависит от режима, фиксировать как максимум сессии |
| DTC P023400 (overboost) | известный дефект серии, TSB EG-00014T-TME |

## Давление топлива (высокий контур D-4T, для Techstream/GTS)

| Условие | Норма |
|---|---|
| Общий рабочий диапазон системы | 2,4–20 МПа |
| Тест ХХ (P/N, A/C off) | **4000–18 000 кПа** |
| Тест 3000 rpm | **8000–18 000 кПа** |
| Давление низкого контура (бак) | в открытых документах не специфицировано |
| ⚠ Отзыв JDM #4961 (27.05.2021) | трещина сварного шва корпуса ТНВД → утечка топлива; проверить выполнение по VIN (глобальная кампания 21SMD-041T) |

## Электрика и прочее

| Параметр | Норма |
|---|---|
| Бортсеть на ХХ | 9–14 В (Toyota SSM); просадки <9 В при работающем двигателе — искать причину |
| Температура масла | рабочее окно примерно как ECT ±10 °C; норматив прогрева не нормируется |
| IAT после стоянки | ≈ уличной; быстрый рост на ХХ — норма (подогрев от двигателя) |

## Что НЕ нормировано в открытых источниках (не выдумывать пороги)

- время прогрева ОЖ в минутах при 0 °C;
- MAF на холостом ходу;
- давление топлива низкого контура;
- табличные нормы MAP.

→ Оценивать по динамике и взаимной согласованности датчиков, см. docs/05.
