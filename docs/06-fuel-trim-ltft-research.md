# 06 · Топливные коррекции: LTFT −14 % на C-HR 1.2T — что это и как проверяем

Дата: 2026-11-23 (обновлено 2026-11-24). Источник наблюдения: первая живая сессия (warm, ХХ прогретого двигателя 63 с,
`stats/20261123_195709_warm_NGX10_summary.md`) + холодная сессия 2026-11-24
(`logs/20261124_020559_cold_NGX10.csv`, ОЖ 19→64 °C, ~13 мин фаст-идла).

## Наблюдение

| параметр | значение на прогретом ХХ (724–735 rpm) |
|---|---|
| LTFT (долгосрочная коррекция) | **−14.1 %, стабильно** |
| STFT (краткосрочная) | 0 … +3.9 % (среднее ~1.9 %) |
| MAF | 1.5–1.6 g/s |
| ОЖ / масло | 88–89 °C / 81 °C |

Интерпретация: STFT ≈ 0 при LTFT −14 % означает, что блок **уже скомпенсировал** устойчивое
обогащение долгосрочной адаптацией; смесь в моменте близка к стехиометрии, но базовая
калибровка считает, что топлива нужно на ~14 % меньше, чем «нарисовано» в базовой карте.

Это формально за пределом бытового «здорового» коридора ±10 % (наш флаг findings сработал),
но до порога DTC Toyota **P0172 ≤ −35 %** далеко.

**Холодная сессия 2026-11-24** (от пуска, ОЖ 19→64 °C, фаст-идл 1161–1274 rpm):

| параметр | значение |
|---|---|
| LTFT | **−11.7 %, плоская линия всю сессию** (значение адаптации, в open loop держится) |
| STFT | −4.7 … +2.3 % (среднее −2.4 %) |
| MAF | 3.2–4.5 g/s на прогревочных оборотах ~1200 |
| DTC (после сессии) | нет кодов (Mode 03/07 пусто) |

Т.е. адаптация уже «выучена» к холодному состоянию (−11.7 %) и на прогрете держится −14.1 % —
это устойчивое смещение во всём диапазоне, а не дрейф конкретной температуры. Следствие:
гипотезы «быстрая переучиваемость» слабеют, остаются калибровка JDM / реальное постоянное
обогащение (форсунки, давление, purge) / особенность разметки MAF.

## Что говорят источники (по Toyota / C-HR конкретно)

1. **Тот же двигатель, та же платформа:** форум adact.ru — «Toyota CHR 2018, 1.2 турбо, P0172,
   богатая смесь» — у владельца коррекции −24…−27 %, MAF 1.7–2 g/s при чистом MAF.
   https://forum.adact.ru/topic/62074-toyota-chr-2018-12-turbo-p0172-bogataja-smes/
   → наши −14.1 % мягче, но симптом в том же семействе: устойчивое обогащение на 1.2T.
2. **Норма MAF на ХХ для Toyota:** ~1.6–1.7 g/s при 650–730 rpm (ToyotaNation, тред
   «Mass air flow sensor reading at idle?», 1.68 g/s @ 650 rpm; drive2-таблица MAF для
   тойот: 1.45 g/s при ~700 rpm).
   https://www.toyotanation.com/threads/mass-air-flow-sensor-reading-at-idle.1652692/
   → наши 1.5–1.6 g/s @ 730 rpm **в норме** — MAФ скорее не завышает.
3. **Причины отрицательного LTFT (общая физика):** утечка(и) форсунок, повышенное давление
   топлива, залипший EVAP-purge, забор воздуха мимо MAF, избыточное давление топлива,
   «богатая» заводская калибровка JDM.
   https://www.scannerdanner.com/forum/post-your-repair-questions-here/12120-negative-long-term-fuel-trim-causes.html
4. **Ключевой диагностический приём — сброс адаптаций:** отключение АКБ на 30+ мин
   обнуляет LTFT; дальше — прогрев и ХХ 5–10 мин без нагрузок, блок переучивается.
   https://au.toyotaownersclub.com/forums/topic/2020-resetting-the-ecu/
   → если после сброса LTFT **быстро** возвращается к −14 % — реальное обогащение (форсунки/
   давление/purge). Если держится около нуля и уходит в минус медленно за много поездок —
   скорее калибровочная особенность JDM-прошивки + накопленная адаптация под конкретное
   топливо.

## План проверки (обновлён 2026-11-24)

1. ✅ Холодная сессия снята 2026-11-24 (запуск двигателя уже шёл, ОЖ 18 °C — почти
   полный прогрев в логе; LTFT на холоде −11.7 %).
2. ✅ В сводке: LTFT на холодной плоский, STFT держится около −2…0 %, MAF на
   прогревочных оборотах 3.2–4.5 г/с.
3. ⏳ Отдельный 3-минутный лог прогретого ХХ (`capture`, пометится warm): усреднить
   STFT+LTFT — суммарная коррекция около −12…−14 %?
4. ⏳ Опционально (решает владелец): сброс адаптаций (АКБ 30+ мин) и контроль скорости
   возврата LTFT — заодно это и мягкий тест на реальную причину.
5. ❌ Давление топлива / purge недоступны: `0x23` (rail_p D-4T) и `0x0B` (MAP) машина
   не поддерживает по OBD (probe 2026-11-24), стандартных PID для purge нет.

## Вердикт-рамка (без паники)

- −14.1 % при STFT≈0 и нормальном MAF, отсутствии DTC и нормальном поведении на ходу —
  **не экстренный** симптом. Порог тревоги Toyota: −35 % (P0172).
- Однако разница с «обычным» коридором ±10 % заслуживает системного наблюдения: именно для
  этого в БД хранится тренд LTFT по всем сессиям (`python -m mycar db`).
